# Final outputs

This directory contains the compact, submission-ready outputs of the project.

| File | Contents |
|---|---|
| `current_results.json` | Complete headline metrics used in the README and report |
| `fssh_summary.csv` | Plain FSSH, Boltzmann-rescaled FSSH, and experiment comparison |
| `coherent_summary.json` | Full/reduced coherent validation, coherence, and current diagnostics |
| `donor_acceptor_channel_flux.csv` | Pair-resolved signed, positive, and absolute integrated fluxes |
| `figures/endpoint_comparison.svg` | Endpoint comparison across methods |
| `figures/positive_flux_channels.svg` | Ranked dynamically active transfer channels |
| `figures/net_flux_channels.svg` | Ranked net-forward and net-backward channels |

The multi-gigabyte raw trajectories and frame-resolved arrays are computational intermediates, not final submission outputs, and are excluded from Git.
